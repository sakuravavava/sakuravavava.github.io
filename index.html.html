        💎 基本 ＆ 基礎能力値
        力 → 攻撃力増加
        器用さ → 回避増加、ブロック増加、クリティカルヒット増加
        精度 → 正確さ増加、クリティカルヒット増加
        意志の力 → ステータス効果耐性
        知能 → ステータス効果確率増加
        体力 → HP増加
        攻撃 → 基本攻撃力
        防御 → 基本防御力
        正確さ → 命中率に影響する、対象の回避、ブロック量によって相殺される
        回避 → 相手の正確さを上回った時に回避が発生する、最大50%
        クリティカルヒット → クリティカルヒットする確率で対象のクリティカルヒット抵抗によって減少する、最大80%
        クリティカルヒット抵抗 → クリティカルヒットを受ける確率を減らす
        HP / MP → 基本生命力 / 特定のスキル発動に必要
        戦闘速度 → 攻撃速度、詠唱速度に影響する
        移動速度 → 足が速くなる
        ⚔️ 特殊戦闘効果 ＆ 条件付き属性
        浸透 → 防御無視
        マルチヒットチャンス → 攻撃が複数ヒットする確率、最大4ヒット
        ブロック → パリーする確率、テンプラとクレリックのみシールドブロック判定もある、対象の正確さとブロック貫通の数値に影響する
        耐久 → ダメージが半減する確率、対象の耐久貫通に影響する
        再生 → 食べたダメージの一部を回復する確率、対象の再生貫通に影響する
        完璧なチャンス → 武器の最大ダメージに基づいてダメージを増加させる確率、対象の完璧な抵抗に影響する
        スマイト → 最終ダメージに基づいてダメージを大幅に増加させる (PvEは2倍 / PvPは1.5倍)、対象のスマイト抵抗に影響する
        ステータス効果(スタンチャンス系) → 状態異常をいれる確率、対象の各ステータス耐性に影響する
        回復ブースト → ヒール用に影響する
        回復の到来 → 受けるヒール量に影響する
        クールダウン → スキルのクールダウンに影響する、最大60%
        スタミナ → ダッシュ、回避で消耗する
        飛行パワー → 飛行時のスタミナ
